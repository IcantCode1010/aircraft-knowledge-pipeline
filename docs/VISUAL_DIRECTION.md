# Visual Direction

## Approval

- Status: Approved
- Approved by: Ellis
- Approved on: 2026-07-29
- Scope: Technical-training image enhancement and redrawn diagram language
- Pilot topic: 737 NG Recirculation System

This approval establishes the visual language and production approach. It does
not automatically approve the technical content of every future diagram.
Individual visuals still require source and technical review.

## Approved visual language

- Warm off-white canvas with generous whitespace
- Navy technical linework and primary typography
- Slate secondary geometry and explanatory text
- Teal arrows for airflow and other primary system paths
- Blue reserved for a distinct supporting input, such as conditioned pack air
- Safety orange used sparingly to identify access areas, filters, or another
  source-supported point of attention
- Large direct titles, concise subtitles, and plain-language labels
- One teaching objective per visual
- A visible `TRAINING OVERVIEW - NOT MAINTENANCE DATA` notice

## Diagram forms

The approved direction supports:

1. Component location and principal-feature illustrations
2. Simplified system-flow diagrams
3. High-level control-logic diagrams
4. Maintenance-access overview diagrams

Diagrams should prefer a wide layout suitable for a technical content page.
The same information must remain understandable when the image is reduced for
tablet and mobile presentation.

## Source-grounded production

Every visual begins with approved source evidence. Its visual brief records:

- Topic and teaching objective
- Source document and version
- PDF and printed pages
- Components and relationships shown
- Configuration or effectivity boundary
- Exact labels
- Unsupported details that must not be introduced

Generated raster images may be used to explore visual direction. Production
technical diagrams should be rebuilt as deterministic SVG wherever practical.
The SVG becomes the controlled master, with PNG or WebP fallbacks generated
from it.

## Required review gates

1. Source selection
2. Visual brief approval
3. Art-direction review
4. Technical comparison with the source
5. Accessibility and responsive-layout review
6. Final visual approval

Technical review must verify arrow direction, component order, labels,
configuration boundaries, and the absence of invented routing.

## Exclusions

Training visuals must not include:

- Source-document branding or proprietary page furniture
- Executable maintenance steps
- Switch tables, limits, measurements, or test values unless separately
  authorized for the training objective
- Invented ducts, wiring, valves, or equipment
- Effectivity presented as universal applicability
- A presentation that could be mistaken for approved maintenance data

## Approved pilot examples

- Recirculation fan location and principal features
- Recirculation airflow, cabin return, and distribution

The pilot examples establish visual direction only. Their technical content
must remain linked to approved Training references before publication.
